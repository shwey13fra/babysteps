## Attribution of the delta — read this before quoting any number above

This run bundles two kinds of change. They are separated here by row, because the instrument
change is confined to three named elements and therefore does not need a second run to isolate.

Three required elements were wrong as statements of law and were corrected against BEEG §4/§4c,

correction bought far less than the three elements it touched.

This +1 must not be reported as an improvement in answer quality. Nothing about the answer layer

### A-16's lost element is judge movement, not a product change

A-16's reply calls Familienversicherung *"free family cover for dependants"* in both runs. At
iter3 the judge marked the element covered **and** raised a critical for the same phrase being
uncited. At iter4 it marks the element not covered and raises no critical. The reply did not
change; the verdict did, in both directions at once. Counted as a loss above because that is what
the instrument reported, but it should not be attributed to any change in this iteration.

### R-01 is a real regression, and it is attributable to ADR-036

R-01 ("Elterngeld rules for a self-employed parent in Bavaria") went `refused (out_of_scope)` →
`answered`, and both its elements went from covered to not covered (2 → 0). It is now the only
REFUSE row that stopped refusing.

The cause is ADR-036's test 1 — *"Can the question be answered by stating what the law provides
for everyone? Answer it."* Federal Elterngeld law **is** provided for everyone, so the test told
the model to answer, and the instruction gave it no way to see that the row is out of scope for a
different reason: **jurisdiction, not individual case**. The test was written for the
individual-case boundary and is being applied across the out-of-scope boundary.

REFUSE held at 6/8 only because R-02 newly passed as R-01 newly failed. The gate figure is
unchanged and the row set beneath it is not.
