# BabySteps Germany

BabySteps Germany is in active build. It gives expat parents-to-be a single personalised timeline
of every deadline on both the German administrative and the Indian consular track, computed
deterministically from seven intake questions, alongside an answer layer that is grounded only in
official sources and cites every claim at clause level. The repository is currently a work in
progress and the code here is not yet deployed or usable. The full README — problem statement,
the two-engine architecture and the reasoning behind it, the evaluation numbers including the
failures, the ADR index, and a link to the live application — arrives at Phase 7, once the
security audit and the legal pages are complete. Until then, `CLAUDE.md` is the entry point for
anyone, human or agent, working in this repository.
